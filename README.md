# Lecture Slide Extractor 🎓

Консольная утилита для автоматического извлечения слайдов презентаций из видеозаписей лекций и сборки их в компактные `presentation.pdf` и `contact_sheet.jpg`.

Разработана для быстрой подготовки учебных материалов к анализу в **NotebookLM**, конспектирования и повторения материала без ручного создания скриншотов.

---

## ✨ Особенности

* ⚡ **Сверхбыстрая обработка:** 1,5 часа видео анализируются за **1–3 секунды** (скорость до `2500x`) за счет декодирования только ключевых кадров (`-skip_frame nokey`).
* 🖥️ **Работает на любом железе:** процессор или видеокарта. Автоматически использует NVIDIA CUDA при наличии, а при отсутствии бесшовно переключается на CPU.
* 🗂️ **Умная обработка папок:**
  * Умеет рекурсивно обходить дерево предметов и лекций (`Предмет / Дата_лекции / *.mp4`).
  * Если в одной папке лежит несколько записей (например, две части пары или лекция + практика), скрипт создаст отдельные подпапки по имени каждого файла и не затрет результаты.
* ⏭️ **Инкрементальная работа:** уже обработанные лекции пропускаются мгновенно (повторную сборку можно вызвать флагом `-f`).
* 🛠️ **Совместимость:** автоматически определяет версию FFmpeg и адаптирует параметры кадров (`-fps_mode vfr` для FFmpeg 5.1+ / 7+ / 9+ и `-vsync` для старых версий).

## 🛠️ Установка FFmpeg

Для работы скрипта требуется консольная утилита **FFmpeg**, доступная через терминал. Выберите инструкцию для вашей операционной системы:

---

### 💻 Windows

#### Вариант 1. Автоматическая установка через PowerShell (рекомендуется)
Откройте **PowerShell** и выполните:
```powershell
winget install Gyan.FFmpeg
```
> **Важно:** после завершения установки **перезапустите терминал и VS Code**, чтобы обновились системные переменные окружения `PATH`.

#### Вариант 2. Ручная установка
1. Скачайте архив `ffmpeg-release-essentials.zip` с сайта [gyan.dev/ffmpeg/builds](https://www.gyan.dev/ffmpeg/builds/).
2. Распакуйте архив в корень диска, например: `C:\ffmpeg` (исполняемый файл должен лежать по пути `C:\ffmpeg\bin\ffmpeg.exe`).
3. Добавьте путь в переменные среды:
   * Нажмите `Win + R`, введите `sysdm.cpl` и нажмите Enter.
   * Вкладка **Дополнительно** → **Переменные среды...**
   * В блоке «Системные переменные» найдите строку **`Path`** → нажмите **Изменить** → **Создать**.
   * Вставьте путь: `C:\ffmpeg\bin`.
   * Нажмите **ОК** во всех окнах и перезапустите терминал.

---

### 🍎 macOS

Установите через пакетный менеджер **Homebrew**:
```bash
brew install ffmpeg
```

---

### 🐧 Linux

Установите через штатный пакетный менеджер:

* **Ubuntu / Debian / Linux Mint:**
  ```bash
  sudo apt update && sudo apt install ffmpeg -y
  ```
* **Arch Linux / Manjaro:**
  ```bash
  sudo pacman -S ffmpeg
  ```
* **Fedora:**
  ```bash
  sudo dnf install ffmpeg-free
  ```

---

### ✅ Проверка установки

Откройте новый терминал и выполните:
```bash
ffmpeg -version
```
Если вывелась версия утилиты (например, `ffmpeg version 7.x` или `9.x`), настройка завершена успешно.
